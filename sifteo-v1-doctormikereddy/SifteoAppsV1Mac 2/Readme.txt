OK, firstly you should already have Siftrunner installed. If you need a copy of this, head to the Sifteo Resurrected web site at: 


http://doctormikereddy.com/sifteo-resurrecting-a-legend/


Put plist file in Preferences folder, and the rest of the SiftRunner folder in Application Support/Sifteo. You might need to run this command in Terminal:

defaults read ~/Library/Preferences/com.sifteo.Sync.plist
